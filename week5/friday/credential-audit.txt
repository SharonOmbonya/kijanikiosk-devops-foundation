Credential Audit Report
Project: KijaniKiosk CI Pipeline
Date: 2026-07-21

Purpose:
This audit verifies that credentials are not exposed in the Week 5 CI pipeline files, commit history, or build output. Jenkins credential binding is used to provide Nexus authentication securely during publishing.

Check 1: Jenkinsfile Credential Scan

Command:
grep -nEi "password|secret|token|username" Jenkinsfile

Result:
The scan identified only credential variable references used by Jenkins Credentials Binding:
- NEXUS_USER
- NEXUS_PASS
- NEXUS_TOKEN

No plaintext passwords, secrets, or authentication values were hardcoded in the Jenkinsfile.

Status:
PASS


Check 2: Git History Credential Scan

Command:
git log --all -p | grep -iEi "password|secret|token"

Result:
The scan returned only expected CI credential handling references such as:
- NEXUS_PASS
- NEXUS_TOKEN
- withCredentials configuration

No exposed Nexus passwords or authentication tokens were found in the pipeline history.

Status:
PASS


Check 3: Build Log Credential Scan

Command:
grep -iEi "password|secret|token" week5/friday/green-pipeline-run.txt

Result:
The only matching output was a masked Jenkins credential entry:
NEXUS_TOKEN=YWRtaW46****

The actual credential value was hidden by Jenkins masking and was not exposed.

Status:
PASS


Check 4: Week 5 Submitted Files Credential Scan

Command:
grep -Rni "_auth\|NEXUS_PASS\|NEXUS_USER" week5/friday

Result:
Only expected Jenkins credential references and masked build output entries were found.
No plaintext credentials were stored in the Week 5 submission files.

Status:
PASS


Check 5: Credential Handling Review

Review:
The Jenkins pipeline uses withCredentials to retrieve Nexus username and password securely.
The generated authentication file (.npmrc) is created only during the Publish stage and removed within the same shell step after publishing.

Result:
Credentials are managed through Jenkins secrets and are not stored directly in the repository or pipeline configuration.

Status:
PASS


Final Audit Summary

The Week 5 KijaniKiosk CI pipeline passed the credential audit.

No plaintext passwords, secrets, or Nexus authentication tokens were found in:
- Jenkinsfile
- Week 5 pipeline build logs
- Week 5 submitted project files

Credentials are provided only through Jenkins Credentials Binding during runtime.

Overall Audit Status:
PASS
