
| Stage Faulted | Fault Introduced | Observed Behaviour | Design Rationale |
|---|---|---|---|
| Lint | Replaced the valid lint command (`npm run lint`) with an invalid npm script (`npm run lint-does-not-exist`) to simulate a lint failure. | Lint failed immediately because the npm script did not exist. Build, Verify, Archive, and Publish stages were skipped. Post actions executed cleanup and failure notification. | Lint runs first as a quality gate. A failure here prevents invalid code from progressing further through the pipeline. |
| Build | Replaced the dependency installation/build command with an invalid npm command (`npm run build-does-not-exist`) to simulate a build failure. | Lint completed successfully. Build failed because the npm script did not exist. Verify, Archive, and Publish stages were skipped. Post actions executed cleanup and failure notification. | A failed build means no reliable artifact exists, so later verification, storage, and publishing stages must not run. |
| Test (Verify branch) | Added `exit 1` after `npm test` to force the Test branch to fail. | Lint and Build completed successfully. Within the Verify parallel stage, the Test branch failed while the Security Audit branch completed successfully. Archive and Publish were skipped. Failure post actions executed cleanup and notification. | Test failures indicate the application does not meet quality requirements. Publishing an unverified artifact must be prevented. |
| Archive | Changed the artifact archive path to a non-existent directory (`nonexistent-dir/**`) to simulate an artifact archival failure. | Lint, Build, and Verify completed successfully. The Archive stage failed because no matching artifacts were found. Publish was skipped. Post actions executed cleanup and failure notification. | Artifact storage is required before publishing. If artifacts cannot be archived safely, the pipeline should prevent publishing incomplete or unavailable build outputs. |
| Publish | Changed the Nexus credential ID to an invalid credential (`wrong-id`) to simulate a publishing authentication failure. | Lint, Build, Verify, and Archive completed successfully. Publish failed because Jenkins could not find the required credentials. The artifact remained archived in Jenkins but was not published to Nexus. | Publishing depends on valid authentication. A failed publish should stop repository delivery while preserving the verified archived artifact. |
